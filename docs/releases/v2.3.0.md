## 新增

- 加入「深色／淺色」模式，浮窗、設定及說明視窗即時同步，並儲存外觀選擇。
- 剪貼簿選項改為膠囊開關，整列可點擊，亦支援 Space／Enter 操作。

## 改善與修正

- Windows 11 視窗外框改用系統原生平滑圓角，移除透明色鍵與硬裁切造成的鋸齒。
- 內部按鈕及麥克風底圈改用抗鋸齒繪製，加入按鈕懸停、按下及鍵盤焦點效果。
- 保留浮窗半透明效果、無細邊框外觀，以及設定與說明視窗的單例行為。
- 改善切換主題時的錄音、快捷鍵錄製及提示色彩狀態，避免按鈕外觀遺失。
- 保留剪貼簿與外觀設定，舊設定或無效主題會回退至深色。

## 驗證與使用

- 35 項測試通過，並完成 Python 語法檢查及深淺模式實際畫面檢查。
- 下載 `CantoneseVoiceInput.exe`，需要 Windows 10／11 64 位元及已安裝 Chrome。
- Windows 11 以外系統使用圓角後備裁切，平滑度可能不同。內部控制項是自訂繪製，並非 WinUI 原生元件。
- EXE 未作程式碼簽署，部分裝置仍可能顯示 SmartScreen 或防毒警告；停用 UPX 並不等於保證沒有誤報。
- `SHA256SUMS.txt` 提供執行檔完整性校驗。
