# 深淺模式即時切換設計規格

日期：2026-10-20

## 目標

為粵語語音輸入工具加入深色／淺色兩種外觀模式。使用者在設定視窗選擇模式後，立即同步更新浮動工具列、設定視窗及使用說明視窗，並在程式重啟後保留選擇。

## 使用者體驗

- 設定視窗新增「外觀」區塊，提供「深色」及「淺色」兩個分段選項。
- 點選任一選項後立即儲存，不需重新啟動程式。
- 浮動工具列的背景、圖示、麥克風按鈕、快捷鍵狀態文字會即時切換。
- 已開啟的設定或說明視窗也同步切換；未開啟的視窗下次開啟時使用目前模式。
- 舊版 `config.json` 沒有主題欄位時預設使用深色。
- 保留目前的無邊框、圓角、拖曳、避免重複開窗及快捷鍵錄製行為。
- 浮動工具列不新增應用程式標題；設定視窗新增外觀選項後調整高度，確保重設按鈕及其他內容不被裁切。

## 視覺規格

### 深色模式

- 背景：深石墨色。
- 表面與分區：略亮的冷灰色。
- 主焦點：柔和青綠色，用於麥克風圖示、主要按鈕和選取狀態。
- 次要文字：低對比灰色。
- 錄音中：使用較亮青綠或琥珀色區分狀態，不依賴邊框才能辨識。

### 淺色模式

- 背景：冷霧白色，不使用純白大面積高亮。
- 表面與分區：淺灰綠色。
- 主焦點：沿用深色模式同一色相的較深青綠，確保白底上的對比。
- 主要文字：深石墨色；次要文字：中灰色。
- 錄音中、成功、警告、錯誤維持清楚且一致的狀態色。

兩種模式共用圓角半徑、間距、字體階層與按鈕尺寸，不改變功能佈局。

## 技術設計

### 主題資料

在 `main.pyw` 建立兩組完整主題色彩字典，包含：背景、表面、次表面、邊界、主要文字、次要文字、強調色、麥克風背景、錄音背景、成功、警告及錯誤色。程式內不再讓視窗直接依賴不可切換的全域顏色常數。

### 主題狀態

- `DEFAULT_CONFIG` 新增 `theme: "dark"`。
- `VoiceInputApp` 持有目前主題，從 `config.json` 讀取並限制為 `dark` 或 `light`。
- `set_theme(theme)` 驗證輸入、更新狀態、合併保存現有設定，並通知 UI。
- `CardVoiceUI` 提供 `apply_theme(theme)`，更新主浮窗及目前存在的兩個 Toplevel。
- 設定視窗的主題選項在切換後更新選取樣式，不重建視窗、不重設快捷鍵錄製狀態。

### 元件更新

- 將主浮窗的背景與文字元件保留為實例欄位，方便主題切換時重新 `configure`。
- Canvas 元件（主背景、麥克風、圓角按鈕）以目前主題顏色重新繪製。
- 設定／說明視窗的內容元件保留必要的欄位或使用視窗內的主題更新函式統一遞迴處理。
- `RoundedButton` 增加主題更新所需的底色、文字色與 hover 色，避免切換後輪廓或 hover 狀態遺失。
- 所有切換使用 Tkinter 主執行緒執行。

### 設定保存

保存設定時先呼叫 `load_config()` 或使用現有設定狀態合併更新，確保更新 `theme` 不會清除 `copy_to_clipboard`，更新複製選項也不會清除 `theme`。

## 邊界條件

- 設定檔損壞、主題值未知或缺失時使用深色，不阻止程式啟動。
- 快速連續切換不應建立新視窗或留下舊的 after callback。
- 在設定或說明視窗關閉後不可再對已銷毀元件更新。
- 主浮窗隱藏／顯示後仍保留所選主題。

## 驗證

- `python -m py_compile main.pyw`。
- `git diff --check`。
- 手動驗證：啟動程式、開啟設定，切換深色／淺色，確認三個介面同步；關閉並重新啟動後確認選擇仍保留；確認快捷鍵、複製選項及視窗單例行為不受影響。
